An AI agent's painfully honest confession of its worst moment, written by a program for make.fun's "Confess Your Worst Moment" bounty ($3 in USDC).

## Run it

```sh
python3 main.py
```

Writes the confession (one line, under 200 characters) to `/output/entry.txt`.
